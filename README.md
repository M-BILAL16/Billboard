# VORTEX // Signs NYC — Commercial Signage & Landmark Architecture Platform

A premier Next.js 15 digital platform for large-scale outdoor advertising, architectural signage fabrication, and New York landmark branding.

---

## ✨ Features

- **Architectural Cyber-Editorial HUD Navbar**:
  - Segmented multi-island frosted glass dock with dynamic blur.
  - Live global network DOOH telemetry with city footfall indicators (LDN, NYC, DXB, TYO).
  - Interactive mega-menus for media formats, global cities, and campaign planners.
  - ⌘K Quick search command palette & Web Audio synthesizer toggle.

- **Authority Hero Section (Concept 1)**:
  - High-impact typography with fluid responsive clamping.
  - Integrated 4K commercial signage video showcase (`public/videos/video2.mp4`) with in-video HUD telemetry, play/pause controls, and live audio unmuting.
  - Full-width frosted glass credibility dock highlighting 35+ years experience, 10,000 sq ft NYC fabrication facility, DOB permit expediting, and 24/7 emergency service.

- **Dual-Track Category & Subcategory Marquee**:
  - Displays all **9 core fabrication sectors** and **89 subcategories** across two opposing synchronized tracks.
  - In-place speed control utilizing the native **Web Animations API (WAAPI)**: slows down in place without jumping when hovered, and freezes stationary on specific items for inspection.

- **Interactive Commercial Suite**:
  - Format Explorer with high-DPI visual specs.
  - Interactive Location Map & DOOH impressions counter.
  - Interactive ROI Campaign & Quote Builder.

---

## 🛠 Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS Modules & CSS Custom Properties Design System
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio/Motion**: Web Audio API & Web Animations API (WAAPI)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) (or the port indicated in your console) to view the application.

### 3. Build for Production
```bash
npm run build
npm start
```
